# Interactive Garden
A tiny interactive garden. Pick a flower, tap anywhere to plant it, and read what your garden says.


## Live Demo

Open the live page here: `https://bhumika-2oo7.github.io/interactive-garden/`


## How to Use

1. Choose a flower .
2. Click or tap anywhere in the garden to plant it.
3. Plant more flowers and watch the sentence.
4. Press **Clear garden** to start over.


## The Flowers

| Flower | Meaning |
| Rose | love |
| Sunflower | loyalty |
| Daisy | a fresh start |
| Lavender | calm |
| Iris | good news |
